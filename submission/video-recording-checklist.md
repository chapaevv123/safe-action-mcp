# Video recording checklist

## Before recording

- [ ] Use the verified public URL or a clean local build of the final commit.
- [ ] Set the browser to 1920×1080 and 100% zoom.
- [ ] Close personal tabs, notifications, password managers, bookmarks bar, and developer overlays.
- [ ] Reset the demo and confirm effect count is zero.
- [ ] Test microphone level; record voiceover separately in a quiet room.
- [ ] Confirm no real booking, payment, wallet, API key, or personal address is visible.

## Capture

- [ ] Move the pointer deliberately and pause briefly after each state change.
- [ ] Keep the mutation diff, one-effect counter, duplicate suppression, and receipt readable.
- [ ] Avoid terminal footage unless a two-second protocol proof is essential.
- [ ] Record one backup take.

## Edit

- [ ] Target 2:20–2:40; hard maximum below 3:00.
- [ ] Use cuts instead of long loading waits.
- [ ] Normalize narration; keep music absent or low-volume and copyright-safe.
- [ ] Add accurate English captions.
- [ ] Use only the approved short overlays.
- [ ] End on project name, safety badge, and hackathon track.

## Export and review

- [ ] Export 1920×1080 H.264 with readable UI text.
- [ ] Watch once muted for visual clarity and once audio-only for narration clarity.
- [ ] Confirm no unsupported security, Alexa+, or production-readiness claim.
- [ ] Upload manually to public YouTube or Vimeo and update submission links.
