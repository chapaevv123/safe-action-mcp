# Final voiceover

AI agents can call increasingly powerful tools. But what happens when the action executed is no longer the action you approved?

Safe Action MCP is a self-hosted MCP execution firewall for consequential agent actions. This Alexa+-style simulated experience uses real MCP initialization, discovery, and tool calls over Streamable HTTP.

The agent proposes a local home-service appointment hold. Before consent, a versioned risk manifest, executable evidence contract, and freshness checks must pass. The owner then approves these exact material arguments: provider, service, date, time, price, currency, and location.

Now the proposed price changes from eighty-nine to one hundred twenty-nine dollars after approval. Safe Action MCP identifies the changed field and blocks execution. Consent is not a vague yes. It is bound to one exact action.

The original approved request can execute, but only inside the reversible simulator. One local hold is created. No provider is contacted and no payment occurs.

Next, we inject a crash after the effect but before workflow finalization. Replay reconstructs the persisted activity, sees that it already completed, and suppresses a duplicate. The side-effect count remains one.

Finally, the result is verified against persisted state, reconciled, and linked through request, evidence, trust, consent, bound action, activity, result, and DecisionReceipt. Every consequential step is inspectable.

Safe Action MCP makes agent tool execution bounded, recoverable, and inspectable. It is an Alexa+-style simulated experience built for the Amazon Build, Ship, Shape Alexa+ track.
